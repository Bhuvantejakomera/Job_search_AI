# Search Queries for Job Scraper

## Installed Portals & Target Search Engines
- **Indeed (`in.indeed.com` / `indeed.com`)** - Primary job portal for India and remote tech roles
- **LinkedIn (`linkedin.com/jobs`)** - Global tech, AI, and developer opportunities
- **Freehire (`freehire.me`)** - Open ATS tech listings

## Query Categories (AI & Software Engineering Focus)

### Priority 1: Generative AI, LLM & AI Agents
Matches strongest skills in RAG, LLM Evaluation, Transformers, PyTorch, and Ollama.

```
site:in.indeed.com/viewjob "Generative AI" OR "LLM" (intern OR fresher OR junior)
site:in.indeed.com/viewjob ("RAG" OR "Prompt Engineer" OR "AI Engineer")
site:indeed.com/viewjob ("Generative AI" OR "LLM Engineer") remote
site:linkedin.com/jobs "Generative AI Engineer" India OR Remote
site:linkedin.com/jobs "LLM Engineer" India OR Remote
```

### Priority 2: Machine Learning, Deep Learning & Vision AI
Matches Vision Transformer (ViT), PyTorch, NLP, and Medical AI research projects.

```
site:in.indeed.com/viewjob ("Machine Learning Engineer" OR "Computer Vision") "PyTorch"
site:in.indeed.com/viewjob "AI Engineer" ("Deep Learning" OR "Vision Transformer")
site:linkedin.com/jobs "Machine Learning Intern" OR "ML Engineer" India
```

### Priority 3: Data Analytics & Data Science
Matches experience at Edulyt India, SQL, Python, Power BI, and analytics dashboards.

```
site:in.indeed.com/viewjob ("Data Analyst" OR "Data Scientist") "Python" "SQL" (intern OR junior)
site:in.indeed.com/viewjob "Power BI Analyst" OR "Data Analytics Intern"
site:linkedin.com/jobs "Data Analyst Intern" India
```

### Priority 4: Python & Full-Stack Software Engineering
Matches full-stack internship (Exposys Datalabs), Next.js, Django, REST APIs, and database engineering.

```
site:in.indeed.com/viewjob ("Python Developer" OR "Full Stack Developer") (junior OR intern)
site:in.indeed.com/viewjob ("Django" OR "Next.js" OR "FastAPI") developer
site:linkedin.com/jobs "Python Developer" India OR Remote
```
